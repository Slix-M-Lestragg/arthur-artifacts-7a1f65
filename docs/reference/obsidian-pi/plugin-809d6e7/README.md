# obsidian-pi

Desktop-only Obsidian plugin that brings pi into a vault: spawns the `pi` CLI over stdio, manages per-vault pi instances, and can connect to AHP hosts over WebSocket.

See the plugin docs in [`./docs`](./docs):

- [`technical.md`](./docs/technical.md) — plugin internals and architecture.
- [`remote-pi-from-obsidian.md`](./docs/remote-pi-from-obsidian.md) — using a remote pi from Obsidian.
- [`host-agent-farm-view.md`](./docs/host-agent-farm-view.md) — host-agent relay: register local pi instances with the Farm View server so all devices see them.
- [`headless-workflows.md`](./docs/headless-workflows.md) — headless / server-side workflows.
- [`RELEASE_CHECKLIST.md`](./docs/RELEASE_CHECKLIST.md) — release process.

For the vault-level ROADMAP and TESTING scenarios, see the vault root [`ROADMAP.md`](../../ROADMAP.md) and [`TESTING.md`](../../TESTING.md).
